## 你该买哪个版本

两台 Windows 电脑，需求是共用一套键鼠、能复制粘贴、能拖文件，买单用户版，不用犹豫。5 台的上限你连一半都用不到，专业版的功能一个都触发不了。

三到五台机器，单用户版还撑得住。只要你的用法还是“跨屏操作加传文件”，就不必升级。

想把笔记本当台式机的第二块屏幕用，买专业版。这是唯一一个理由足够硬的场景，¥70 换一块随插随用的副屏，比再买一台显示器便宜。

机器超过 5 台，或者需要在外面把家里的机器唤醒，也只能专业版。这两类需求都比较极端，撞上了就没得选。

用 Mac 或 Linux 的人，两个版本都别买。Multiplicity 4 只支持 Windows 10 和 11，没有 macOS 版，跨平台得去看 Synergy 那类方案。工作环境里混了 Mac 的，这款软件帮不上忙。

还有一种人也不该买：只是偶尔在台式机和笔记本之间拷个文件。网盘、局域网共享文件夹、微信文件传输助手都能解决，为一年几次的操作装一套 KVM 软件不划算。👉 [按你的机器数量和用法对照两个版本](https://lizhi.shop/products/multiplicity?cid=7bbix2xj)

## 第三方评价与几个真实的坑

真正容易踩坑的地方在条款里，不在功能上。

**发货后不退。** 商店的购买须知写明，数字商品一经交付，除当地法律另有规定或另有售后政策外，不接受退款。这意味着你付完钱拿到激活码，发现两台机器连不上，钱是要不回来的。买之前一定先下试用版，在你实际要用的那两台机器、那个网络环境里跑一遍。

**买断不等于以后所有版本都免费。** 购买须知里专门写了一段：“Lifetime”“One-time Purchase”“永久更新”这类表述依据开发商提供的信息，后续的更新、维护和策略变更由开发商负责，商店不作补偿或退款承诺。翻译成日常话就是，你买的是当下这个版本的永久使用权，Stardock 以后出大版本要不要再收钱，商店不打包票。

**局域网环境决定成败。** 软件走局域网连接，公司网络的隔离策略、跨网段、防火墙规则都可能让连接失败。这类问题不是软件缺陷，但会让你觉得钱白花了。试用阶段就在真实环境里测。

**授权只给一个人用。** 共享、转售、出租都是明确禁止的，出了事后果自负。想和朋友合买的，趁早放弃这个念头。
